# Модуль обработки ошибок в заявках (Г3)

Предварительная реализация, Python 3.10+. Без сторонних зависимостей.
В каталоге `data/` разместить `applications_raw.csv` (не добавлять в Git).

```sh
python -m rail_validator inspect data/applications_raw.csv
python -m unittest discover -s tests
```

Разметка, справочники и оригинальный README датасета ещё не получены.
Этот этап не является готовым baseline или полной версией решения.

## Что реализовано

- CSV-адаптер, диагностика полей, сохранение строковых ID.
- Отложенные 20% от train по app_id, seed=42 (предлагаемая настройка).
- Локальные проверки ИНН, длины кодов станций, дат и положительных чисел.

Проверка ИНН использует стандартный алгоритм для 10 цифр до сверки с README датасета. Форматы дат предварительные. Для справочных проверок, автоисправлений, оценки качества и очереди оператора потребуются остальные файлы. Ни одна заявка этим кодом не изменяется автоматически.
